All media in this directory is original project artwork, generated specifically for CareClaim.

- `careclaim-walkthrough.mp4`: 16-second 960×540 H.264/YUV420p silent animated introduction, MP4 fast-start enabled.
- `walkthrough-poster.webp`: first-scene preview image.
- `walkthrough.en.vtt`: English text captions for the four scenes.
- `careclaim-calm.wav`: original 24-second, 22050 Hz, 16-bit stereo instrumental loop synthesized with sine tones. The welcome page attempts low-volume playback on arrival when browser autoplay policy allows it; an explicit Enable sound control handles blocked playback. Mute, pause, reduced-motion and background-tab behavior remain under visitor control.
- `doctor-patient.jpg`: original fictional doctor-and-patient photograph created with the built-in image generation tool, optimized to a 197 KB JPEG for sign-in and the dashboard. The exact prompt and provenance are in `doctor-patient.prompt.md`.
- `generate_assets.py`: reproducible original asset generator; install Pillow and imageio-ffmpeg, then run with Python. Windows Segoe UI or Linux DejaVu Sans is used to render text.

The video uses synthetic people, claims, policy names, and transactions. It contains no recorded personal information and no spoken narration. The music is optional ambient sound, with no therapeutic claim.
